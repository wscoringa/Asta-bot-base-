🔥 Sobre o Bot

O ASTA BOT é uma base de bot para WhatsApp desenvolvida em Node.js, utilizando a biblioteca Baileys.

Inspirado no universo de Black Clover, o projeto busca oferecer uma estrutura personalizável para quem deseja criar seu próprio bot, adicionar comandos e desenvolver novas funcionalidades.

---

✨ Recursos

- ⚔️ Base para bot de WhatsApp
- 👑 Estrutura para comandos personalizados
- 🏓 Comando de ping
- 📜 Menu de comandos
- ⚡ Desenvolvido em Node.js
- 📱 Compatível com Termux
- 🔧 Código personalizável
- 🔌 Conexão com WhatsApp via Baileys

---

📥 Instalação — Termux

1️⃣ Atualize os pacotes

pkg update && pkg upgrade -y

2️⃣ Instale os requisitos

pkg install nodejs git python -y

3️⃣ Clone o repositório

Substitua "SEU-USUARIO" pelo seu nome de usuário do GitHub.

git clone https://github.com/SEU-USUARIO/ASTA-BOT.git

4️⃣ Entre na pasta do bot

cd ASTA-BOT

5️⃣ Instale as dependências

npm install

6️⃣ Inicie o bot

npm start

Siga as instruções exibidas no terminal para conectar o WhatsApp.
